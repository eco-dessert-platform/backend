# TDD 개발 가이드

## 순서

1. **Red**: 프로덕션 코드 작성 전, 성공 케이스 + 여러 실패/예외 케이스 테스트를 먼저 작성한다. 테스트가 실패하는 것을 확인한다.
2. **Green**: 테스트를 통과시키는 최소한의 프로덕션 코드만 작성한다.
3. **Refactor**: 테스트가 계속 통과하는지 확인하면서 코드를 정리한다.

테스트 코드 작성 컨벤션(BDD Mockito, given/when/then, Fixture 등)은 [test-write 스킬](../test-write/SKILL.md)을 따른다.
