# Method / Endpoint / 설명

- 커스터머가 장바구니에서 선택한 상품 옵션을 삭제합니다.
- "상품삭제" (1-1): 체크박스가 활성화된 옵션의 cartOptionId를 넘겨 삭제합니다.
- "품절상품삭제" (1-2): FE에서 품절·판매종료 상태인 옵션의 cartOptionId를 수집하여 동일 API로 삭제합니다.
- 삭제 후 해당 CartItem(Board) 하위에 CartOption이 0건이 되면 CartItem도 함께 삭제합니다.

| # | Method | Endpoint                          | 설명             |
|---|--------|-----------------------------------|------------------|
| 1 | DELETE | `/api/v1/customer/carts/options`  | 장바구니 상품 삭제  |

> **화면 위치**: 장바구니 > 상품삭제 버튼 (1-1) / 품절상품삭제 버튼 (1-2)

# 구현 시 주의사항

### 권한 검증
- CartOption → CartItem → Cart → Member 경로로 소유자를 확인합니다.
- 요청한 커스터머의 `memberId`와 `Cart.member.id`가 일치하는 경우에만 삭제를 수행합니다.

### CartItem 자동 정리
- CartOption 삭제 후 해당 CartItem에 남은 CartOption이 없으면 CartItem도 함께 삭제합니다.
- `CartItem.options`에 `orphanRemoval = true`가 설정되어 있으므로 컬렉션에서 제거하면 DB에서도 삭제됩니다.

### 삭제 처리
- 상품 상태(정상/품절/판매종료)와 무관하게 요청된 ID는 모두 삭제합니다.
