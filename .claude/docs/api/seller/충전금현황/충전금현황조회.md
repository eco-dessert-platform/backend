# Method	Endpoint	설명

- 판매자의 현재 충전금 잔액과 기간 필터로 조회한 충전금 거래내역 목록을 반환합니다.
- 기본 조회 기간: 최근 1주일 / 최대 조회 기간: 1년

| # | Method | Endpoint                        | 설명         |
|---|---------|---------------------------------|------------|
| 1 | GET    | `/api/v1/seller/charge-balance` | 충전금 현황 조회  |

# **Request 헤더**

| key           | 설명       | value 타입 | 옵션               | Nullable | 예시                             |
|---------------|----------|----------|------------------|----------|--------------------------------|
| Authorization | 인증 토큰    | String   | Bearer Token     | N        | Bearer eyJhbGciOiJIUzI1NiJ9... |

# Path Variable

- 해당없음

# **Query parameter**

| key       | 설명     | value 타입  | 옵션                         | Nullable | 예시         |
|-----------|--------|-----------|----------------------------|----------|------------|
| startDate | 조회 시작일 | LocalDate | yyyy-MM-dd / 기본값: 오늘 - 7일  | Y        | 2025-03-01 |
| endDate   | 조회 종료일 | LocalDate | yyyy-MM-dd / 기본값: 오늘       | Y        | 2025-03-07 |
| page      | 페이지 번호 | Integer   | 0부터 시작                     | Y        | 0          |
| size      | 페이지 크기 | Integer   | 최대 100 / 기본값: 20           | Y        | 20         |

> ⚠️ endDate - startDate 최대 365일. 초과 시 에러 반환

# Request Body

- 해당 없음

# Response Body

```json
{
  "success": true,
  "code": 0,
  "message": "SUCCESS",
  "result": {
    "chargeBalance": 2000000,
    "content": [
      {
        "baseDate": "2025-09-01",
        "settlementId": "250401A1F7",
        "category": "ACCUMULATE",
        "amount": 123456,
        "status": "PENDING"
      }
    ],
    "page": 0,
    "size": 20,
    "totalElements": 14,
    "totalPages": 1,
    "hasNext": false
  }
}
```

| **key**                      | **설명**        | **value 타입** | **옵션**   | **Nullable** | **예시**       |
|------------------------------|---------------|--------------|----------|--------------|--------------|
| result.chargeBalance         | 현재 충전금 잔액     | BigDecimal   |          | N            | 2000000      |
| result.content               | 충전금 거래내역 목록   | Array        |          | N            |              |
| result.content[].baseDate    | 일자            | LocalDate    | yyyy-MM-dd | N          | 2025-09-01   |
| result.content[].settlementId | 정산 ID         | String       | 일별 고유 식별자 | N           | 250401A1F7   |
| result.content[].category    | 구분            | String (Enum) | 아래 Enum 참고 | N          | ACCUMULATE   |
| result.content[].amount      | 금액            | Long         |          | N            | 123456       |
| result.content[].status      | 상태            | String (Enum) | 아래 Enum 참고 | N          | PENDING      |
| result.page                  | 현재 페이지        | Integer      |          | N            | 0            |
| result.size                  | 페이지 크기        | Integer      |          | N            | 20           |
| result.totalElements         | 전체 건수         | Long         |          | N            | 14           |
| result.totalPages            | 전체 페이지 수      | Integer      |          | N            | 1            |
| result.hasNext               | 다음 페이지 존재 여부  | Boolean      |          | N            | false        |

### **category Enum (구분)**

| **값**          | **설명**              |
|----------------|---------------------|
| `ACCUMULATE`   | 적립 (충전금 잔액 증가)      |
| `DEDUCT`       | 소진 (충전금 잔액 감소)      |

### **status Enum (상태)**

| **값**         | **설명**                          |
|---------------|----------------------------------|
| `PENDING`     | 대기 (충전 신청 후 무통장입금 전 상태)         |
| `COMPLETED`   | 완료                               |
