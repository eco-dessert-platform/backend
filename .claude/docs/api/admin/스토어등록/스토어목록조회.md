# GET `/api/v1/admin/stores/registered` — 스토어 목록 조회

- 관리자가 등록된 전체 스토어 목록을 페이지네이션으로 조회합니다.
- 스토어명, 사업자번호, 한줄소개, 대표전화번호, 서브전화번호, 이메일, 기본주소, 상세주소를 반환합니다.
