- 관리자가 등록된 스토어를 한 번에 여러 개 삭제합니다.
- 소프트 딜리트(`SoftDeleteBaseEntity`) 방식으로 처리됩니다.
- 삭제 확인 모달("잠깐! 스토어를 삭제하시겠어요?") 확인 후 호출됩니다.
