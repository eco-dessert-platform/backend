# GET `/api/v1/admin/products` — 관리자 상품 목록 조회

- 전체 상품(Board) 목록을 페이지네이션으로 조회합니다.

| # | Method | Endpoint                  | 설명             |
|---|--------|---------------------------|----------------|
| 1 | GET    | `/api/v1/admin/products`  | 관리자 상품 목록 조회   |

# **Request 헤더**

| key           | 설명       | value 타입 | 옵션               | Nullable | 예시                             |
|---------------|----------|----------|------------------|----------|--------------------------------|
| Authorization | 인증 토큰    | String   | Bearer Token     | N        | Bearer eyJhbGciOiJIUzI1NiJ9... |
| Content-Type  | 요청 본문 타입 | String   | application/json | N        | application/json               |

# Path Variable

- 해당없음

# **Query parameter**

| key  | 설명     | value 타입 | 옵션               | Nullable | 예시               |
|------|--------|----------|------------------|----------|------------------|
| page | 페이지 번호 | Integer  | 1부터 시작           | N        | 1                |
| size | 페이지 크기 | Integer  | 기본값 20           | N        | 20               |
| sort | 정렬 기준  | String   | createdAt,desc   | Y        | createdAt,desc   |

# Request Body
