# Method	Endpoint	설명

- decisionType 값에 따라 승인(PENDING → ON_SALE) 또는 거절(PENDING → BANNED) 처리합니다.

| # | Method | Endpoint                                    | 설명                |
|---|--------|---------------------------------------------|-------------------|
| 1 | POST   | `/api/v1/admin/products/{boardId}/decision` | 업로드 상품 승인/거절 (통합) |

# **Request 헤더**

| key           | 설명       | value 타입 | 옵션               | Nullable | 예시                             |
|---------------|----------|----------|------------------|----------|--------------------------------|
| Authorization | 인증 토큰    | String   | Bearer Token     | N        | Bearer eyJhbGciOiJIUzI1NiJ9... |
| Content-Type  | 요청 본문 타입 | String   | application/json | N        | application/json               |

# Path Variable

| **key** | **설명**         | **value 타입** | **옵션** | **Nullable** | **예시** |
|---------|----------------|--------------|--------|--------------|--------|
| boardId | 처리할 상품(게시글) ID | Long         |        | N            | 101    |

# **Query parameter**

- 해당 없음 x

# Request Body

승인시

```json
{
  "decisionType": "APPROVE"
}
```

거절시

```json
{
  "decisionType": "REJECT",
  "rejectCategory": "INAPPROPRIATE_BRAND_NAME",
  "rejectReason": "브랜드명을 무단으로 사용하여 고객에게 혼동을 줄 수 있습니다."
}
```

| **key**        | **설명**            | **value 타입**  | **옵션**          | **Nullable**    | **예시**                   |
|----------------|-------------------|---------------|-----------------|-----------------|--------------------------|
| decisionType   | 처리 유형             | String (Enum) | APPROVE, REJECT | N               | APPROVE                  |
| rejectCategory | 거절 사유 카테고리 (드롭다운) | String (Enum) | 아래 Enum 참고      | Y (REJECT 시 필수) | INAPPROPRIATE_BRAND_NAME |
| rejectReason   | 거절 상세 사유 (텍스트에리어) | String        | 최대 500자         | Y               | 브랜드명을...                 |

### **rejectCategory Enum (`decisionType = REJECT`시 사용)**

| **값**                         | **설명**          |
|-------------------------------|-----------------|
| `ADMIN_JUDGMENT`              | 관리자 판단 부적합      |
| `INAPPROPRIATE_BRAND_NAME`    | 브랜드명 무단사용       |
| `OFFICIAL_MATERIAL_CONFUSION` | 공식물 오인 가능       |
| `INAPPROPRIATE_EXPRESSION`    | 비속어/부적절한 표현     |
| `PROHIBITED_STORE_EXPRESSION` | 상품명/카테고리명 포함    |
| `CONTAINS_ADVERTISING`        | 광고성 문구 포함       |
| `CONTAINS_CONTACT_INFO`       | 연락처/URL 포함      |
| `CONTAINS_COMPETITOR_NAME`    | 타 판매자명 유사       |
| `DIRECT_INPUT`                | 직접입력            |

# Response Body

```json
{
  "success": true,
  "code": 0,
  "message": "SUCCESS"
}
```

| **설명**  | **value 타입** | **옵션**  | **Nullable** | **예시** |
|---------|--------------|---------|--------------|--------|
| success | 요청 성공 여부     | Boolean |              | N      |
| code    | 응답 코드        | Integer | 0: 성공        | N      |
| message | 응답 메시지       | String  |              | N      |
